# 성균관대 IMBA 46기 · 2026년 1학기 수업 시간표

## 📌 프로젝트 개요

성균관대학교 IMBA 46기 원우들을 위한 2026년 1학기 수업 시간표 검색 웹사이트입니다.  
**실제 46기 원우 명단(90명)** 과 수강 과목 데이터가 반영되어 있습니다.

---

## ✅ 완성된 기능

### 1. 원우 시간표 검색 탭
- 이름 검색 (자동완성 드롭다운)
- 원우 카드 그리드 (이름순·과목수순 정렬)
- **다중 원우 선택** → 선택된 원우 칩(Chip) 표시
- 선택된 원우들의 시간표 표시
- **뷰 모드 3종**: 목록 / 주차별 / 월별
- **수업 타입 필터**: 전체 / 오프라인 / 화상Q&A

### 2. 전체 시간표 탭
- 월별 탭 (3월~9월) 전환
- 날짜별 카드 형식 시간표 표시
- 교시별 과목명·교수명·회차 표시
- 오프라인 / 화상Q&A 필터

### 3. 캘린더 뷰 탭
- 월별 캘린더 (이전/다음 월 이동)
- 특정 원우 선택 시 해당 원우 수업만 표시
- 날짜 클릭 → 당일 수업 상세 슬라이드 표시
- 오프라인 / 화상Q&A 필터

### 4. 과목별 조회 탭
- 전 과목 카드 그리드 (담당교수·수강인원·수업횟수)
- 과목 클릭 → 수강 원우 목록 + 전체 수업 일정
- 수강 원우 클릭 → 검색 탭으로 이동하여 해당 원우 선택
